# DSH 打卡

[English](README.md) | 中文

通过 DSH 对话或宿主右侧打卡 Tab 管理日常打卡。每个主题每天只有“完成”或“未完成”两种状态，数据使用 Node 内置 `node:sqlite` 保存在当前 Host，本机所有工作区与会话共享。

## 安装

需要 DSH `0.1.5-rc.1` 和 Node.js `^22.19.0 || >=24.0.0`。可从仓库安装；正式环境建议固定到已验证的提交：

```sh
dsh plugin --profile web add github:zsspub/dsh-checkin
```

安装后重启该 DSH profile，并刷新页面。Git 仓库包含编译产物，安装时不需要编译插件。也可以安装 `pnpm pack` 生成的 tarball。

## 对话打卡

- “新建一个阅读打卡主题。”
- “今天阅读打卡完成了。”
- “补签昨天的阅读，查看本月完成情况。”
- “撤销昨天的阅读打卡。”
- “把阅读主题改名为读书。”
- “删除运动主题和它的全部打卡记录。”

Agent 会先查询主题，再使用精确 ID 操作；主题指代不清时会澄清。删除主题会永久删除该主题的全部记录。撤销某一天只删除当天记录，不删除主题。

## 右侧打卡 Tab

点击左侧栏底部“打卡”，宿主会打开或聚焦右侧打卡 Tab。默认显示当前月份，每天显示“完成数 / 当前主题数”。切换主题可查看单个主题的完成状态；选择日期后，在下方清单完成或撤销打卡。每个主题旁有重命名与删除入口，删除需要确认。

日期统一使用北京时间。可以补签任意过去日期，未来日期只读。不设主题开始日期，因此新增或删除主题也会改变历史总览的分母。月历支持方向键移动日期、Home/End 移到月初/月末；Tab 的关闭、分栏、浮动和全屏由宿主右栏统一提供。

Tab 可见且页面可见时默认每 3 秒刷新；手动写入后立即读取，重新显示或页面恢复可见时也会刷新。保存失败保留输入，错误区提供重试。

## 数据与配置

默认数据库为 `$DSH_HOME/checkin/checkin.sqlite3`。浏览器不保存打卡数据。SQLite 使用 WAL、外键、事务和版本迁移；更高版本的数据库会被拒绝打开。

在 profile 的 `cordis.patch.yml` 中覆盖 `checkin` 行配置：

```yaml
- id: checkin
  config:
    databasePath: !!js dshHomePath('checkin/checkin.sqlite3')
    busyTimeoutMs: 5000
    refreshIntervalMs: 3000
```

数据库路径必须是绝对路径；锁等待至少 1 毫秒，刷新间隔至少 250 毫秒。主题名称去除首尾空白后须为 1–200 个字符，不能与现有名称完全相同。

备份时先停止使用该数据库的 DSH 进程，再复制数据库文件。不要把数据库、WAL 文件或凭据提交到公开仓库。

## 开发与验证

```sh
pnpm install
pnpm run check
```

`check` 包含构建、类型检查、lint、数据库／工具／UI 测试和打包检查。工具输出快照无需 API key。真实模型及浏览器验收记录见 [验证说明](docs/verification.md)。

首版不提供提醒、奖励、备注、计数目标、归档或云同步。
